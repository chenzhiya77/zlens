# T07 — 项目分布 / 性能分位数 / 健康度三视图

**Blocked by:** T04 — 按项目 + 性能 + 健康度端点; T05 — 前端壳 + 总览视图页
**Status:** ready-for-agent

## User story

作为关注体验与稳定性的用户,我想直观看到项目用量占比、响应快慢的分位数图形和健康度面板——补齐 zlens 的差异化三视图。

## What to build

三个数据视图:按项目(占比图 + 明细表)、性能(duration 与 TTFT 的 P50/P90/P99 图形化,TTFT 展示有效样本数)、健康度(重试率指标卡、错误类型/错误码分布、context 超限与取消计数)。沿用 T06 的取数与三态设施。

## Acceptance criteria

- [ ] 三视图数值与各自端点一致;TTFT 图表旁可见样本数说明
- [ ] 无项目归属的数据有明确归类展示,不与其他项目混淆
- [ ] 错误分布为零时健康度面板呈现"干净"状态而非空白报错
- [ ] `make check` 全绿
