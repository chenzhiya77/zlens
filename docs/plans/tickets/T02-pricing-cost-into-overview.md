# T02 — 价格表与成本估算接入总览

**Blocked by:** T01 — 最小数据通路:meta + 总览(token 口径)
**Status:** ready-for-agent

## User story

作为关心成本的用户,我编辑本地价格文件并刷新页面,总览就出现各模型与合计的美元成本(明确标注"估算");而内部模型等无定价者永远只显示 token 数。

## What to build

成本估算层:加载版本化价格表(USD / 1M tokens,input / output / cache_read / cache_write 可选档位),对 overview 响应追加金额字段(总计与按模型),并输出"未计价模型清单"(供 meta 端点透出)。价格文件路径经配置注入,测试用临时文件替代。模板文件已随仓库分发,真实价格文件不入库。

## Acceptance criteria

- [ ] 价格表中存在的模型,overview 出现对应金额;金额等于各档 token 除以百万乘单价之和(合成数据下精确可断言)
- [ ] 价格表缺失的模型金额位置呈现明确的"未计价"状态,且出现在 meta 的未计价清单中
- [ ] 价格表缺少 cache_write 档时,该项成本记零,其余档位照常计价
- [ ] 不重启服务、仅修改价格文件后刷新,金额随之变化(热加载)
- [ ] 页面/API 层面对金额带有"估算"语义标记;`make check` 全绿

## Architectural decisions

- **禁止硬编码单价**:所有折算必须经过价格表;这保证内部模型不会被猜出一个错误金额。
- **热加载优先于启动快照**:价格表是用户随手改的配置,不是部署产物。
