# T27 — 运行质量页时间范围窗口(近 1 小时 / 24 小时 / 7 天 / 全部 / 自定义)

**Blocked by:** None —— `/api/performance`、`/api/health` 已有 `?source=`(T18/T26),缺的只是时间窗口。
**Status:** done (2026-09-02)

## User story

作为用户,我想在运行质量页选时间范围:刚切了新模型,看「近 1 小时」它稳不稳;
排查昨夜的问题看「近 24 小时」;「近 7 天」看趋势;「全部」仍是 T26 的累计口径;
「自定义」让我框定某段日子。画布 2:2 画了前四项但控件未渲染(T26 out-of-scope),
本票连同自定义一并落地。

## What to build

后端给两个运行质量端点加**时刻级窗口**,前端加 seg 并翻译预设。

1. **后端窗口参数**:`/api/performance`、`/api/health` 新增 `since` / `until`
   (ISO datetime,**naive 按本地时间**——应用唯一的时钟)。语义为**半开区间
   `[since, until)`**:日期级自定义正好映射 `[起日 00:00, 止日+1 00:00)`,
   不用编造 23:59:59.999 这类假上界。`since > until` → 422(同 `get_window` 的先例)。
   缺省 = 全量,行为与之前完全一致。
2. **下推三适配器**(同 T15 的下推纪律,不在 API 层拿全量再筛):
   zcode 在 SQL 层比 `started_at`(epoch ms)原始列——小时级窗口不能走 `date(...)`
   的日切表达式;minimax / opencode 在记录装载后按 ms 边界过滤。
   minimax 本就无耗时/重试/错误字段,窗口只影响请求总数,不编数据。
3. **前端 seg**:近 1 小时 / 近 24 小时 / 近 7 天 / 全部 / 自定义,渲染在页头控制区。
   预设是**滚动时长**(监控页语义:刷新后「近 1 小时」跟着现在走),锚点是「现在」,
   由前端在每次请求时翻译成绝对 `since`——沿用「后端不猜锚点」的既定分工(T15)。
   自定义是**日期级**(起止日两个 date 输入,同总览),翻译成半开 datetime。
4. **URL 是唯一视图状态容器**(同 T24/T26):`window`(预设名)+ `start` / `end`
   (自定义日期)。刷新/前进后退/分享还原同一视图;预设刷新时按当前时刻重新翻译。
   切到自定义时预填近 7 天,URL 里的区间永远合法、请求永不带空日期。
5. **窗口贯通本页所有请求**:主 performance / health 与分源对比卡的逐源请求都带
   同一窗口——对比卡三行请求数之和 = 健康结论栏请求数的对账在任意窗口下保持成立。
6. **文案随窗口**:副标题「累计口径 · …」在「全部」时保持 T26 原文,其余显示
   窗口名或自定义区间;底部口径注同步。自动刷新仍为 5 分钟,文案不变。

## Acceptance criteria

- [x] seg 五项可切换;performance / health(含分源对比卡)请求带 `since`/`until`,
      全部卡片由后端按窗口重算;「全部」不带窗口参数、行为与 T26 完全一致
- [x] 半开边界:恰在 `since` 的请求计入,恰在 `until` 的不计入(离线断言)
- [x] `since > until` → 422;畸形 datetime 由 FastAPI 422
- [x] 三个适配器各有离线窗口用例(窗口内/外/边界);`make check` 全绿
- [x] live 三源冒烟:近 24 小时下分源对比卡合计 = 健康结论栏请求数
- [x] URL 持久化成立;custom 预填合法区间
- [x] README / CHANGELOG 同步

## Out of scope

- 分钟级自定义输入(自定义是日期级,与总览能力对齐;时分输入等有真实需求再说)。
- 总览/趋势等日窗口端点(它们已有 `start`/`end`,不动)。
- meta 端点加时刻窗口(本页副标题的请求数直接用窗口化 health 的 `request_count`)。

## Architectural decisions

- **半开 `[since, until)`** 与 DateWindow 的闭区间不同,是刻意的:日期级自定义的
  换算在半开下零舍入;文档写清楚,不混用两套闭/开语义。
- **预设 = 滚动时长,前端翻译**。监控页的「近 1 小时」刷新后应当滑动;若存绝对
  时刻,一夜过后页面还钉在昨天的窗口,读数会静默变空。与 Overview「URL 存预设、
  请求时翻译」同一模式,只是锚点从「今天」变成「现在」。
- **窗口只进运行质量两个端点**:它是采样/计数查询的过滤器,与 token/成本无关,
  不触碰四档与未计价规则。
