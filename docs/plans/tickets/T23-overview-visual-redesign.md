# T23 — 总览页视觉改版(阶段 A)

**Blocked by:** None — 零后端依赖,可与后端所有票并行
**Status:** ready-for-agent

## User story

作为用户,我打开总览页就先看到"这期花了多少钱"这个最大的数字,下面一排辅指标解释
钱花在哪,再往下是逐模型明细——而不是现在这样六格 KPI 平铺、主次不分。

## What to build

按 Ardot 设计稿 `719793184410961`「AI用量总览-优化版」重做 `frontend/src/pages/Overview.tsx`
的视觉结构:

- **Header**:页面标题 + 数据范围/数据源/生成时间说明行
- **Hero 主指标卡**:按量消耗金额(大字号)+ 环比位(本阶段留空)+ 估算口径说明
- **5 张 KPI 卡**:总请求次数 / 累计 Token / 缓存读 Token / 输出 Token / 实购支出
- **按模型明细表格**:沿用 `ModelTable` 组件
- **页脚**:数据更新时间 + 版本号

**本阶段零后端改动**,只用现有字段。周期选择器、来源 chips、搜索框、排序、合计行、
导出、自动刷新**都不在本票范围**(→ T24)。

### 关键的低成本前提:不需要新建设计 token

设计稿的配色与本项目 `frontend/src/index.css` 里 `html[data-mode="light"]` 翻出来的
zinc 色阶几乎完全一致。用现有的 `bg-zinc-900` / `border-zinc-800` / `text-zinc-500`
去搭结构即可,**两种主题自动都成立**。不要改全局默认主题,不要新建色板。

### 必须纠正的设计稿缺陷(别照抄画布像素)

## Architectural decisions

- **只换视觉,不动数据流**。现有 `ModelTable` 的列(含「未计价」null 处理与别名输入框
  失焦回灌)已经覆盖了设计稿的表格需求,直接沿用。
- **主题靠 token 而非硬编码颜色**。设计稿的十六进制值只作为对照参考,
  实现时用 zinc token,这样 dark 模式自动成立,不需要维护两套样式。
- **留空而不是占位**。本阶段还没后端的字段(环比、命中率)一律不渲染,
  绝不用 `0%` / `—` 之类的占位符顶上——那会让用户误以为是真的测量结果。
