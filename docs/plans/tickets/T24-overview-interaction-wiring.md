# T24 — 总览页交互接线(阶段 B)

**Blocked by:** T18 — 来源枚举;T19 — 表格排序;T20 — 合计行
**Status:** done (2026-08-29)

## User story

作为用户,我想要设计稿上画出来的那些交互全都能用:切周期、按来源过滤、搜模型、
点表头排序、看合计、导出、以及页面上标明的一小时自动刷新。

## What to build

在 T23 的视觉结构之上接上交互。后端能力由 T15–T22 提供,本票负责前端接线与剩余 UI。

1. **周期选择器**:近 7 / 30 / 90 天 + 全部 + 自定义区间。「全部」不带 `start`/`end`,
   其余由前端翻译成绝对日期后请求。
2. **来源 chips**:全部 / zcode / miniax / opencode。数据来自 T18 的 `meta.sources`;
   不可用来源置灰并显示 `error`。切换时**所有卡片与表格由后端重算**——
   **禁止前端拿 `by_model` 本地 filter 后自己求和**,那会绕过"任一渠道未计价则总额为 null"。
3. **搜索框**:纯客户端过滤(model_id + localStorage 别名),不发请求。
4. **表头排序**:7 个数值列可点,默认「成本(估算)」降序,由后端排(T19)。
   表头需补排序指示器样式(升序/降序箭头)——设计稿缺这个。
5. **合计行**:数据来自 T20 的 `Overview.totals`,文案「全部合计 · 共 N 个模型」。
   成本为 null 时显示「未计价」,不是 `¥0.00`。
6. **导出按钮**:调用 T22 的 `/api/export`,文件名带日期。
7. **自动刷新**:总览与趋势查询加 `refetchInterval: 3_600_000`。
   页脚文案「每小时刷新一次」必须与真实行为一致——不写死承诺。
8. **URL 持久化**:`sort` / `order` / `source` / 窗口全部进 query,刷新、前进后退、
   分享链接都能还原同一张表。
9. **趋势图**:定长窗口 → 按日折线;「全部」→ 按月柱状图(T17)。
   ECharts 设 `connectNulls: false`——未计价的日子成本是 null,折线必须断口,
   补 0 等于画一条假的下降。
10. **环比显示**(T16 落地后):红涨绿跌。**`delta` 或 `change_rate` 为 null 时不渲染**,
    不允许显示 "—%" 或 0%。
11. **缓存命中率显示**(T21 落地后):KPI3 附一行「缓存命中率 X%(按 token 计)」。
    必须带「按 token 计」的说明,避免被误读成请求命中率。

## Acceptance criteria

- [ ] 周期切换 → 所有卡片、表格、趋势图随窗口变化(后端重算)
- [ ] 来源 chip 切换 → 同上;不可用来源置灰并带原因
- [ ] 搜索框按 model_id 与别名过滤表格(纯客户端)
- [ ] 表头点击排序,默认成本降序,未计价行恒排最后;表头有排序指示器
- [ ] 合计行数据来自 `totals`;任一模型未计价 → 成本合计显示「未计价」
- [ ] 导出按钮下载 `.md` 文件
- [ ] 刷新间隔为 1 小时,页脚文案与之一致
- [ ] `sort`/`order`/`source`/窗口进 URL,刷新后视图状态保持
- [ ] 趋势图在定长窗口为折线、「全部」为柱状图;未计价处断口不补 0
- [ ] 环比为 null 时不渲染该处;命中率带「按 token 计」说明
- [ ] 明暗两主题下都正常;窄屏不破版
- [ ] `make check` 全绿;三来源真实数据 live 冒烟通过

## Out of scope

- 分页:规格已决定不做
- 表头排序的 UI 之外的表格重构 = T23 已完成

## Architectural decisions

- **所有筛选与聚合都走后端参数**,前端不做任何"先取全量再本地筛"的捷径。
  这条不只是性能:未计价判定、四档归一、窗口边界都是业务口径,前端复制必然算出不同的数。
- **唯一允许前端做的过滤是搜索框**,因为它过滤的是显示行而非聚合值,
  不影响任何金额与总量。将来若引入服务端分页,搜索必须同步改为服务端参数。
- **URL 是唯一的视图状态容器**。不引入额外的状态管理:总览页的状态就这四项,
  放进 query 同时解决了刷新、前进后退、链接分享三个需求。
- **null 一律不渲染或显示「未计价」**,任何一处显示成 0 都算 bug。
