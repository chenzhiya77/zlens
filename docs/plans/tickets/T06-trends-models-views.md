# T06 — 日趋势图 + 模型排行视图

**Blocked by:** T03 — 日趋势 + 按模型端点; T05 — 前端壳 + 总览视图页
**Status:** done (2026-08-29)

## User story

作为多模型用户,我想在页面直接看到日趋势折线图和模型排行榜,而不是去读 JSON。

## What to build

两个数据视图:日趋势(ECharts 折线/面积,请求次数与主要 token 维度可切换)、按模型排行(provider+model 表格或条形,token 与估算金额列,未计价行特殊标注)。react-query 取数,统一的加载中 / 错误 / 空数据三态。

视觉参照 ZCode"使用统计"面板:趋势视图顶部提供时间范围分段控件(近 7 日 / 近 30 日 / 全部);折线为按模型着色的多序列(图例色点对应模型);另提供 GitHub 风格 Token 活动热力图,支持每日 / 每周 / 累计三种粒度(数据复用日趋势端点的全年聚合);模型视图附占比环形图(图例含模型名、百分比与 token 数)。

## Acceptance criteria

- [ ] 两个视图在合成 fixture 场景下渲染正确(数值与端点响应一致)
- [ ] 时间范围分段控件(近 7 日 / 近 30 日 / 全部)切换即时生效
- [ ] 日趋势为按模型着色的多序列折线,图例色点与模型一一对应
- [ ] Token 活动热力图支持每日 / 每周 / 累计三种粒度切换
- [ ] 模型视图含占比环形图,图例展示模型名、百分比与 token 数
- [ ] 加载、请求失败(如数据源不兼容降级错误)、空库三种状态均有友好呈现
- [ ] 未计价模型在排行中有明确视觉标识
- [ ] `make check` 全绿
